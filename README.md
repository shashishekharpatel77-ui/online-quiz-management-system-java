# Online Quiz Management System (Java)

## Overview

The Online Quiz Management System is a console-based Java application developed using Object-Oriented Programming (OOP) principles. This project allows users to register, manage quiz questions, display available questions, and calculate quiz scores. It was built to strengthen core Java concepts and improve problem-solving skills through a practical application.

---

## Features

- User Registration
- Add Quiz Questions
- Display Quiz Questions
- Start Quiz
- Automatic Score Calculation
- Console-Based User Interface
- Object-Oriented Design
- Easy to Understand and Extend

## How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/online-quiz-management-system-java.git
```

2. Open the project in VS Code or any Java IDE.

3. Compile the Java files.

```bash
javac Main.java
```

4. Run the application.

```bash
java Main
```
